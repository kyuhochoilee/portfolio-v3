Figma for design. VS Code for code. Arc for browsing. Linear for tasks. Notion for everything else. FL Studio for music. Spotify for listening. Claude for thinking.

## The Setup

That's it. No fancy setup. No custom mechanical keyboard. No standing desk. Just a MacBook and whatever cafe has the best wifi.

### Design

- **Figma** — everything lives here. Components, prototypes, design systems.
- **Photoshop** — for photo editing and creative work.
- **InDesign** — printed programs and publications.

### Code

- **VS Code** — with minimal extensions. Prettier, ESLint, that's about it.
- **Terminal** — iTerm2 with a custom theme.
- **GitHub** — where everything lives.

### Music

- **FL Studio** — for production. Been using it since high school.
- **Spotify** — for everything else.

> The tool doesn't matter. The work matters. I've seen people spend more time configuring their setup than actually building things. Don't be that person.

## What I Don't Use

I don't use Slack. I don't use Discord for work. I don't use project management tools with more features than my actual project. Keep it simple.

The tool doesn't matter. The work matters.
