# what up vlog

life’s been full of context switching lately, and i’ve been having trouble finding the momentum to catch my stride and truly go somewhere

within work, in my life - i somehow have all of the time in the world for everything, yet nothing

this weekend, updating my portfolio became my one and only goal. i’ve been down with a sickness, so not much to do otherwise. with claude it feels so stupidly easy to code that it’s actually an incredibly liberating creative experience

more than anything - i can literally just speak my vision to existence. after using claude only for work purposes, this was a super refreshing way of realizing just how sick of a tool this is. i didn’t even have to think, all i had to do was feel, see something that was not there, take it from my thoughts to the canvas, and dictate it with very mediocre communiction

i think this website will now become a very fun project. it was always annoying because i wanted to have a cool functional personal site that was super up to date, but i never would want to touch code like that

now here we are! i literally built my own text editor and cms, just because i felt like it. i was gonna use sanity but i realized id much rather write in something that i hacked together in claude but it is ultimately mine. i love customizing the look and feel to it - and this is exactly what i’ve been needing all along

now hopefully that i’m going to sleep at 4am on a work night
